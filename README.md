# Rock Paper Scissors

A simple __Rock Paper Scissors__ game built with JavaScript as part of The Odin Project Foundations Course.

This is my first JavaScript project in The Odin Project. The game is played entirely through the browser's developer console.

## How it Works

The player plays __5 rounds__ against the computer.

- The computer randomly chooses Rock, Paper or Scissors.
- The player enter their choice through a browser prompt.
- Each round determines a winner and updates the score.
- After 5 rounds, the final winner is displayed in the console.
